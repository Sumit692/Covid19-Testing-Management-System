A web-based application built using PHP and MySQL to manage COVID-19 testing records efficiently. It helps healthcare centers handle patient registrations, test requests, and result tracking through a simple, responsive dashboard.

🔹 Features

Patient registration & test management

Admin and staff login system

Real-time test result tracking

Search & filter functionality

Auto-generated Test IDs

Secure and responsive UI (HTML, CSS, Bootstrap)

🔹 Tech Stack

Frontend: HTML, CSS, Bootstrap

Backend: PHP (Core PHP)

Database: MySQL

Server: Apache (XAMPP/WAMP)

🔹 How to Run

Extract the ZIP file and move the folder to htdocs.

Create a database covidtms in phpMyAdmin.

Import the provided SQL file.

Start Apache & MySQL in XAMPP.

Open:

http://localhost/Covid19-TMS-Project-Using-PHP-and-MySQL/
